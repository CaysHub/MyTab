# MyTab

MyTab 是一个无需构建的 Chromium 新标签页扩展，同时提供 Cookie 管理弹窗。

## 功能

- 新标签页展示最近访问的 20 条网页，可打开或从浏览器历史记录中删除。
- 显示本地日期、精确到秒的时间、农历和节假日状态。
- 白色背景上的点线网络会缓慢移动，鼠标附近的连线会变化；点击空白处可触发向外扩散的圆形涟漪。
- 在扩展弹窗中查看指定标签页的 Cookie，将单个或全部 Cookie 复制到当前标签页及剪贴板，或删除指定标签页的 Cookie。

## 安装

1. 打开 Chrome 或其他支持 Manifest V3 的 Chromium 浏览器，进入扩展管理页面。
2. 开启“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择本项目目录。安装或更新代码后，重新加载扩展并打开新标签页。

项目不依赖打包工具或远程服务。最近访问功能需要在已加载的扩展中使用，直接打开 `newtab.html` 无法读取浏览器历史记录。

## 节假日数据

2026 年的节假日和补班日期按[国务院办公厅公布的安排](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)内置；普通周末单独标记。其他年份尚未录入官方安排时会显示“节假日待核实”，不会猜测。新一年的通知公布后，可更新 `script.js` 中的日期数据。

农历由浏览器内置的中国历法格式化功能生成，日期和时间采用设备本地时区。

## 权限与安全

- `history`：读取最近访问记录，并在点击删除按钮后删除对应网址的浏览历史。
- `tabs`、`activeTab`：识别当前标签页和 Cookie 来源标签页。
- `cookies`、`<all_urls>`：读取、复制或删除用户选择的网站 Cookie。

Cookie 可能包含敏感登录信息。仅在可信页面间使用复制功能；删除历史记录或 Cookie 后，浏览器可能无法恢复这些数据。
