# MyTab

MyTab 是一个无需构建的 Chromium 新标签页扩展，同时提供 Cookie 管理弹窗。

## 功能

- 新标签页展示书签栏的全部书签，可按书签栏一级文件夹切换；各文件夹下的书签不区分层级，直接平铺展示。书签栏根目录中的书签显示在“全部”中。支持编辑书签名称和网址、移动到文件夹的指定位置，以及确认后删除书签。
- 首页支持新增、重命名和删除书签目录，直接同步浏览器书签栏的一级文件夹。新增后自动切换到新目录；选中目录后可重命名或删除。“全部”为固定汇总页。删除目录前会显示目录名称和书签数量，确认后会一并删除该目录及全部子目录、书签。
- 显示本地日期、精确到秒的时间、农历和节假日状态。
- “我的书签”标题右侧显示当前位置的城市 / 区县、天气、温度、风力、湿度和观测时间。点击地区可改用手动城市查询，点击 ↻ 可重新定位并刷新天气（手动城市模式下刷新该城市）。
- 新标签页和 Cookie 管理弹窗统一使用黑白灰暗色主题，采用中性深灰背景、浅色文字和灰白强调色；书签对话框、表单、滚动条和点线动画同步使用灰阶配色。
- 暗色背景上的点线网络会缓慢移动，鼠标附近的连线会变化；点击空白处可触发向外扩散的圆形涟漪。
- 扩展弹窗打开后默认选中当前网页并加载 Cookie，也可切换来源标签页，将单个或全部 Cookie 复制到当前标签页及剪贴板，或删除指定标签页的 Cookie。

## 安装

1. 打开 Chrome 或其他支持 Manifest V3 的 Chromium 浏览器，进入扩展管理页面。
2. 开启“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择本项目目录。安装或更新代码后，重新加载扩展并打开新标签页。

项目不依赖打包工具，天气展示需要联网。书签功能需要在已加载的扩展中使用，直接打开 `newtab.html` 无法读取浏览器书签。

## 天气与定位

天气使用国内的 [UAPI 公开天气接口](https://uapis.cn/docs/api-reference/get-misc-weather)，按当前文档和 2026-10-19 实测无需注册或 API Key。默认先通过浏览器取得经纬度，传给 [UAPI 行政区查询](https://uapis.cn/docs/api-reference/get-misc-district)，取得附近区县的 `adcode`，再查询天气；不会按 IP 猜测当前位置。没有区县层级时尝试查询市级。

需要允许浏览器及操作系统的位置访问。若定位不可用，点击天气区域的“当前位置”，输入完整城市或区县名称（例如“杭州市”或“北京市海淀区”）即可查询；手动城市会保存在当前浏览器，点击“使用当前位置”可切回定位模式。

- 定位时发送三位小数的经纬度（约百米精度），只发送给 UAPI 行政区接口；手动模式只发送城市名称。请求不携带 Cookie。
- 当前浏览器本地仅保存所选城市、查询结果和取数时间，不保存经纬度。天气缓存 10 分钟，期限内新标签页直接复用；再次打开新标签页或切回已过缓存期限的页面时刷新，↻ 按钮可强制刷新。定位模式在缓存过期或强制刷新时重新确认当前位置。
- 超时、限流或网络故障会显示重试提示；已显示的天气会保留并注明“上次结果”。拒绝定位不会自动改用 IP。
- UAPI 是第三方聚合服务，文档未公开可独立核验的完整气象数据源和准确率。坐标反查返回附近行政区，边界附近可能存在偏差；这是区县级天气，不是当前位置的现场测量。应结合界面上的观测时间判断数据时效。公开接口的免费政策、限额及可用性以服务方为准。

对比过的[高德天气接口](https://lbs.amap.com/api/webservice/guide/api/weatherinfo)需要开发者申请 Web 服务 Key，同样按行政区查询；如果后续已有 Key，可再按稳定性、配额及数据需求选择正式供应商。

天气调用约定仅使用以下两个接口：

| 接口 | 本项目传参 | 使用的响应字段 |
| --- | --- | --- |
| `GET https://uapis.cn/api/v1/misc/district` | `lat`、`lng`、`level=district`（必要时 `city`）、`limit=1` | `results[0].country_code`、`results[0].adcode` |
| `GET https://uapis.cn/api/v1/misc/weather` | `adcode` 或 `city`，`lang=zh` | `city`、`district`、`temperature`、`weather`、`wind_direction`、`wind_power`、`humidity`、`report_time` |

天气接口每次请求超时为 10 秒；定位超时同为 10 秒。`report_time` 既可能为北京时间字符串，也可能为“几分钟前发布”，界面会尽量还原为北京时间观测时刻，不用本地取数时间冒充观测时间。

## 节假日数据

2026 年的节假日和补班日期按[国务院办公厅公布的安排](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)内置；普通周末单独标记。其他年份尚未录入官方安排时会显示“节假日待核实”，不会猜测。新一年的通知公布后，可更新 `script.js` 中的日期数据。

农历由浏览器内置的中国历法格式化功能生成，日期和时间采用设备本地时区。

## 权限与安全

- `bookmarks`：读取书签栏，在书签发生变化时更新新标签页，并用于管理书签及书签目录。
- `tabs`、`activeTab`：识别当前标签页和 Cookie 来源标签页。
- `cookies`、`<all_urls>`：读取、复制或删除用户选择的网站 Cookie。
- `geolocation`：获取当前位置用于天气查询。更新扩展后若浏览器要求新增位置权限，请允许，或使用手动城市查询。

Cookie 可能包含敏感登录信息。仅在可信页面间使用复制功能；删除 Cookie 后，浏览器可能无法恢复这些数据。

## 本地验证

基础回归：`node --test test/*.test.js`。未设置 `MYTAB_WEATHER_TEST_BASE` 时，天气 HTTP 用例会跳过；完整回归需先启动下方模拟服务，并带此变量运行相同命令。

天气 HTTP 回归使用从上述公开文档和实测响应整理的本地模拟服务，无需登录或发布到 Postman：先运行 `postman simulation run test/postman/weather.sim.yaml --port 4917 --no-history --output ndjson`，另开终端运行 `MYTAB_WEATHER_TEST_BASE=http://127.0.0.1:4917/uapi/api/v1 node --test test/weather.test.js`。测试使用真实 HTTP 请求覆盖经纬度转区县、中文天气、零度/负温、服务失败及请求超时；模拟响应不代表生产天气服务已完成长期稳定性或准确率验证。
